# Theme Demo Curated Assets

These local demo assets are stored under `public/theme-demo/curated` and used by `ThemeDemoContentGenerator` to avoid runtime dependency on third-party CDNs.

Source note:
- Curated photos in this folder were downloaded from Pexels.
- Pexels license summary: photos can be used for websites/apps, modified, and attribution is not required.
- License reference: https://www.pexels.com/license/

Groups included:
- `phones/smartphones`
- `phones/cases`
- `phones/chargers`
- `phones/watches`
- `phones/speakers`
- `phones/audio`
- `phones/camera`
- `transport/buses`
- `placeholders`

If new preset groups are added, extend local folders first, then map them in `ThemeDemoContentGenerator` before using external fallbacks.
